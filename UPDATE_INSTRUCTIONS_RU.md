# Как обновить существующий репозиторий MoiBudilnik

1. Скачайте архив `MoiBudilnik_v1.2_update_patch.zip` и распакуйте его.
2. Откройте репозиторий GitHub `kavpdtr-cloud/MoiBudilnik` → вкладка **Code** → **Add file** → **Upload files**.
3. Откройте распакованную папку `MoiBudilnik_v1.2_patch` и перетащите всё её содержимое в окно GitHub. Важно: сохраняйте вложенные папки и загружайте файлы в корень репозитория.
4. GitHub покажет добавляемые и заменяемые файлы. Убедитесь, что файлы с теми же путями заменяются, а два новых Kotlin-файла добавляются.
5. Нажмите **Commit changes**.
6. Откройте **Actions**. Новый запуск должен начаться автоматически. Дождитесь зелёного **Success**.
7. Откройте страницу запуска → раздел **Artifacts** → `MoiBudilnik-debug-APK`. Распакуйте ZIP и получите `app-debug.apk`.

Если GitHub не принимает несколько файлов с совпадающими путями, загрузите только содержимое `app/` и `.github/` через **Upload files**, внимательно сохраняя структуру каталогов. Старые файлы проекта вручную не удаляйте.

# Как пользоваться настройками

- При добавлении нового виджета откроется окно настройки.
- Для уже установленного виджета откройте приложение «Мой Будильник» и нажмите `Настроить виджет 1`, `Настроить виджет 2` и т. д.
- На Android 12+ лаунчер также может показывать пункт «Перенастроить» при долгом нажатии на виджет.
- После сохранения настройки применяются сразу к выбранному виджету.

# Проверка обновления будильника

1. Установите обновлённый APK.
2. Убедитесь, что на экране виджета отображается ближайший активный будильник.
3. Откройте системное приложение «Часы» и выключите ближайший будильник.
4. Вернитесь на главный экран. Если HONOR Clock обновляет Android AlarmManager как положено, виджет сразу покажет следующий будильник или сообщение «Нет активных будильников».
5. Если на виджете осталось прежнее значение, откройте приложение «Мой Будильник» и нажмите «Обновить виджеты сейчас». Это покажет, что данные читаются верно, но сам системный сигнал не дошёл от прошивки/приложения Часы.

Примечание: Android `getNextAlarmClock()` возвращает только ближайшее событие, объявленное приложением часов через AlarmManager `setAlarmClock()`, а не полный список всех выключенных/включённых будильников.
