# Исправление перехода к будильникам на HONOR

В предыдущей версии резервный запуск проверял только `com.android.deskclock` и `com.google.android.deskclock`. В исправлении добавлен пакет штатных часов HONOR `com.hihonor.deskclock`.

## Какие файлы заменить в GitHub
Замените содержимое трёх файлов по тем же путям:

1. `app/src/main/AndroidManifest.xml`
2. `app/src/main/java/ru/neurolastic/moibudilnik/MainActivity.kt`
3. `app/src/main/java/ru/neurolastic/moibudilnik/AlarmWidgetProvider.kt`

В ZIP сохранена эта структура каталогов.

## Как внести исправление через GitHub в браузере
Для каждого из трёх файлов:
1. Откройте файл в репозитории.
2. Нажмите карандаш **Edit**.
3. Выделите весь старый текст и замените его содержимым соответствующего файла из распакованного ZIP.
4. Нажмите **Commit changes**.

После изменения всех трёх файлов вкладка Actions автоматически запустит сборку. Дождитесь статуса Success и скачайте новый Artifact `MoiBudilnik-debug-APK`.

## Как обновить приложение на телефоне
Установите APK из новой сборки поверх старого приложения. Не удаляйте старое приложение предварительно. Затем проверьте кнопку в самом приложении и нажатие на виджет на рабочем столе.

## Что изменено
- Добавлен поиск штатных часов HONOR по пакету `com.hihonor.deskclock`.
- Если системная команда `ACTION_SHOW_ALARMS` не поддерживается приложением часов, выполняется запуск основного экрана найденного приложения «Часы».
- Добавлены `<queries>` для видимости известных пакетов на Android 11+.
- Нажатие на сам виджет теперь вызывает ту же процедуру открытия часов, что и кнопка приложения.
- Если часы не найдены, выводится понятное сообщение вместо молчаливого отсутствия реакции.

Примечание: `com.hihonor.deskclock` встречается в базе пакетов устройств HONOR, однако подтвердить конкретный package name именно на данном экземпляре HONOR X8C без диагностики телефона нельзя. Поэтому сохранены альтернативные варианты и стандартный Android intent.
