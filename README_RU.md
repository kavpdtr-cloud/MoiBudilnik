# Мой Будильник — облачная сборка APK без Android Studio

Проект предназначен для Honor X8C и других устройств Android 6.0+.

## Получение APK через GitHub Actions

Workflow `.github/workflows/build-apk.yml` собирает APK на облачном компьютере GitHub. На Windows не требуется устанавливать Android Studio, Android SDK или Gradle.

### 1. Создай репозиторий GitHub
1. Открой https://github.com и войди в аккаунт или зарегистрируйся.
2. Нажми **+** → **New repository**.
3. Назови репозиторий `MoiBudilnik`.
4. Выбери Public или Private.
5. Нажми **Create repository**.

### 2. Загрузи файлы проекта
1. На странице репозитория нажми **Add file → Upload files**.
2. Открой распакованную папку `MoiBudilnik` на компьютере.
3. Перетащи в окно GitHub всё содержимое папки, включая `.github`.
4. Если Windows не показывает `.github`, включи показ скрытых элементов: **Вид → Показать → Скрытые элементы**.
5. Нажми **Commit changes**.

Важно: загружай содержимое папки проекта, а не ZIP как один файл. В корне репозитория должны быть `settings.gradle.kts`, `build.gradle.kts` и папка `app`.

### 3. Запусти сборку
1. Открой вкладку **Actions**.
2. Выбери workflow **Собрать APK**.
3. Если сборка не запустилась автоматически, нажми **Run workflow** → **Run workflow**.
4. Открой задачу **Сборка Android APK**.
5. Дождись зелёной галочки **Success**.

### 4. Скачай APK
1. На странице успешной сборки найди раздел **Artifacts**.
2. Нажми **MoiBudilnik-debug-APK** — скачается ZIP с APK.
3. Распакуй архив. Внутри будет `app-debug.apk`.

### 5. Установи на Honor X8C
1. Передай `app-debug.apk` на телефон.
2. Открой его через «Файлы».
3. Если Android попросит, разреши установку приложений из этого источника.
4. Установи приложение.
5. На рабочем столе удерживай палец на свободном месте → **Виджеты** → **Мой Будильник** → перетащи виджет на экран.

## Что делает приложение
- Читает время ближайшего активного системного будильника через `AlarmManager.nextAlarmClock`.
- Показывает время и дату следующего срабатывания.
- По нажатию на виджет отправляет системную команду открытия раздела будильников.
- Не запрашивает интернет, контакты, геолокацию или доступ к точным будильникам.

## Ограничения
- Android предоставляет стороннему приложению время следующего системного будильника, но не универсальный список всех будильников и дней повтора.
- Обновление происходит при изменении следующего будильника, смене времени/часового пояса и периодически; Android может ограничивать частоту.
- Виджет прозрачный, с белыми символами и тенью. На очень светлых обоях текст может быть менее заметен.
- Переход к будильникам зависит от поддержки стандартного системного действия прошивкой MagicOS.

## Технические параметры
Kotlin; Android Gradle Plugin 8.7.3; Gradle 8.9; JDK 17; compileSdk 35; minSdk 23; targetSdk 35.
